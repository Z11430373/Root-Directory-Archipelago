# 參考研究：主架構師採用界線

使用者提供的是參考，不是替換引擎、擴充指令或移植劇情的授權。本文件只記錄取捨；候選改善尚未實作。

## 現在維持什麼

- 保留目前 29 指令的 ES2020 引擎、原始資料與 Python 對照；不因另一專案的指令更多就替換。
- 任一替換方案仍須通過 T1–T12，特別是四走法的完整 commit ID、VFS inode／分支、讀檔事件與存檔互通。通用 shell 庫不會自動滿足遊戲的這些契約。
- 保持單檔、file://、零執行期網路、嚴格 CSP、既定依賴範圍。沒有新增 Docker、VM、WASM 或新的第三方套件。
- Server 終端與群島介面繼續共用同一遊戲真相。不能為了更像 Linux 而偽造系統能力或修改來源劇情。

## 先借鏡哪些設計

1. **Teach Terminal**：教學狀態明確且可收起；可用純文字表達已做／目前／未做，不必再增加特效。
2. **GameShell**：目標、完成判定、復原各自清楚；不移植其真 Bash 或失敗即重置的策略。
3. **clmystery**：用調查動機帶動讀檔，語法小抄與任務提示分開；不改寫本案成偵探案件。
4. **cmdchallenge**：補完、歷史與焦點離開方式值得檢視；輸入輔助不應自動送出或洩漏題解。

## 引擎組回報後的判斷

- **just-bash** 是較合理的未來 adapter 候選，不是立即替換品。已確認 browser 入口與自訂指令；但固定快照的 Node 要求為 20.19+、有額外依賴與瀏覽器功能差異，跨 exec 的 cwd／環境也要轉接。本案指定讀檔事件、inode／分支及 commit ID 不會自動相容。Apache-2.0 授權材料完備仍不等於已獲准新增依賴。
- **PocketTerm** 的正確參考為 `edgarfurse/pocketterm`，不是同名 Go／SSH 工具。它是 React／xterm 的完整教學應用；查閱快照的 parser 未見 `&&`／`;` 分派，且有持久化／網路與 UI 耦合。較適合參考 UX，不適合整體搬入本案。
- 不用 npm 套件解壓體積假裝最小瀏覽器 bundle 大小，不把靜態程式碼閱讀寫成實跑相容性。若未來另獲授權，應固定版本做隔離 PoC，先過輸出／事件／封裝的驗收門檻再談遷移。

## 後續候選，而非自動開工

- 以現有文字做可收合的操作小抄／任務摘要；不要新增答案、隱藏發現清單或劇情。
- 讓玩家更容易理解 Tab 候選、Shift+Tab 離開、上下鍵歷史；先做鍵盤／輔助科技驗證。
- 分清「語法錯誤」「指令合法但尚未達成任務」「成功」的 UI 回饋；不得擅自放寬或改寫 check。
