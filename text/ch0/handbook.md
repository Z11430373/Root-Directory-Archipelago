# 燈塔機房．值班手冊（rev 5）

> 寫給下一個值班員。字很少，請全部讀完。 —— lin

## 1. 你是誰

你是值班員。你的工作是「在」。
管理員目前不在。請不要等他。

## 2. 燈

燈亮，代表這座島有人值班。燈熄，代表沒有。
燈不會自己亮，也不會自己熄。
（我說過兩次了。第二次是怕你沒看第一次。）

## 3. 四個指令，先學這些

    ls        看有什麼（加 -a 連躲起來的也看）
    cd        走過去
    cat       讀
    grep      找（加 -r 連資料夾裡面都找）

## 4. 島嶼憲章．值班員摘要（Rev 5）

全文在權限堡的 /etc/charter。你現在只需要知道這幾條：

    第一條  島不屬於任何人，包括寫憲章的人。
    第二條  日誌只歸檔，不刪除。
    第三條  動用 root 須三名值班員同時簽核。掛機不算人，
            三人中至少一人必須清醒。
    第六條  GC 單次停頓不得超過一次眨眼
            （150 毫秒，以值班室的標準眨眼貓為準）。
    第九條  修憲須附測試並通過 CI。不得在週五下午修憲。
