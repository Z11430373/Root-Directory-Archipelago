# 試玩版驗收清單（給你的代理／實作者）

> 這份是『真人』與『活動前』的驗收。程式面的驗收（T1–T12）在 `AGENT_BUILD_PROMPT.md`，代理的 `REPORT.md` 會回報。
> 我（Claude）已自動驗證：資料引用、時間預算、指令白名單、存檔來回、竄改、統計、劇透護欄、流程走法（4 條）、真 bash 一致性。
> 以下是**需要在真正的前端裡**確認的事，每項請回報「通過／不通過＋一句話」。不必逐字測試對話。

## A. 15 分鐘節奏
- [ ] 一位沒玩過的人從頭玩到尾，碼表計時。回報：總時間、卡最久的是哪一題。
- [ ] 14:00 出現「值班時間剩一分鐘。」；15:00 自動收尾並問投票。
- [ ] 到時間時進度有保存，值班證與代碼都出現。

## B. 新手友善
- [ ] 指令按鈕點一下會把文字填進輸入列（ls、ls -a、cat、grep、grep -r、cd、git、hint、save）。
- [ ] Tab 補全可用；打 `sl` 會提示「你是指 ls 嗎」。
- [ ] 30／60／90 秒沒輸入，依序出現提示 1、提示 2、完整指令；完整提示之後 `flag.demo.used_full_hint` 被設定。
- [ ] `hint`、`skip` 隨時可用；`skip` 不會造成卡死或空任務。
- [ ] 不在白名單的指令回 `command not found`。

## C. 存檔
- [ ] 每個 commit 後 localStorage 有自動存檔；私密視窗不崩潰。
- [ ] `save code`、`save file`、`save card` 都能用。
- [ ] 代碼 → 貼回 → 還原後狀態與原本一致（任務、旗標、發現、投票、耗時）。
- [ ] 竄改一個字元：被擋，錯誤訊息清楚。
- [ ] 截斷、貼上多餘空白或換行：前者被擋、後者被容忍。
- [ ] 代碼長度 800–1,300 字元；若超過 1,200，是否真的分成兩個 QR。
- [ ] 結尾與值班證上只出現「完整／可疑／損毀」，沒有「已驗證」。

## D. 活動模式
- [ ] kiosk：閒置 120 秒重置；結束後詢問是否清除本機存檔。
- [ ] 結尾「這份代碼包含什麼」確實顯示過一次。
- [ ] host_led：只走 seg1–4 + seg7，10 分鐘內可收尾。

## E. 匯入正式版（等正式版有存檔讀取後再測）
- [ ] 暱稱變成 op-<nick>；F1、R0、K0、Q0-1…Q0-5 在。
- [ ] Q1-1、Q1-3 **不在**；所有 `flag.demo.*` 被丟掉。
- [ ] 聽過 02:00 的人有 `ckpt/ch1-night`；完成 Ch0 的人有 `ckpt/ch1-start`。
- [ ] 竄改過的存檔不給徽章。
- [ ] 已有存檔時，試玩版存檔以平行紀錄匯入，不覆蓋。

## F. 一般
- [ ] 字級可放大、高對比主題可切換、狀態不只靠顏色表達。
- [ ] 試玩版文字沒有劇透碎片總數、沒有出現「八」位守鑰者。
