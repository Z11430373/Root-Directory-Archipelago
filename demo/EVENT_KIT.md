# 活動主持包（辦一場試玩活動）

適合：社團博覽會攤位、學校講座暖場、朋友聚會、作品集展示日。**不需要伺服器、不需要網路也能辦。**

---

## 0. 選一種跑法

| 情境 | 跑法 | 設備 | 每人時間 |
|---|---|---|---|
| 攤位，人來人往 | **kiosk**（一台筆電，閒置 120 秒自動重置） | 1–2 台筆電 | 15 分 |
| 多人各自玩 | **自助**（連結／QR） | 玩家自己的手機或筆電 | 15 分 |
| 20 人以上講座暖場 | **host_led**（投影，舉手決定下一條指令） | 投影機 | 10 分（只走 seg1–4 + seg7） |

---

## 1. 活動前（前一天）

- [ ] 在目標瀏覽器各開一次：Chrome／Safari／手機瀏覽器，完整走完一輪（只要你自己 15 分鐘，不需要找人）。
- [ ] 準備 QR：連結＋一行字「15 分鐘，可存檔，正式版可匯入」。
- [ ] 印一張 A4 看板：口號「正式版開門的時候，燈塔還會是亮的。」＋ `save code` 怎麼貼回來。
- [ ] 準備一個表單或紙本收代碼（見第 3 節）；想收 email 就另設一欄並寫明用途（只用來通知正式版，可不填）。
- [ ] 準備備用筆電一台，已經開著試玩版。
- [ ] 手機充電、延長線、網路備案（手機熱點）。

## 2. 活動中

**開場一句話**（攤位用）：「這是一個用打指令玩的小遊戲，十五分鐘，不會的話它會自己給提示。」

**玩家流程**：輸入暱稱 → 玩 → 結尾看到值班證與存檔代碼 → 請他們**複製代碼貼到收集表單**（或拍照給你）→ 領貼紙／加入通知名單。

**看板提示**（現場常見狀況）：
| 現象 | 你說什麼 |
|---|---|
| 「我完全不會打指令」 | 「右邊有按鈕，點一下就會填進去。」 |
| 卡在同一題超過 1 分鐘 | 「輸入 hint 看看。」（不用你講答案） |
| 想看更多 | 「試著去翻翻看每個資料夾。有 12 個隱藏發現。」 |
| 兩人搶鍵盤 | 輪流，一人一題。 |
| 超過 15 分鐘 | 遊戲會自己收尾，進度保存。 |

**kiosk 模式**：每位玩家結束後，螢幕顯示代碼＋值班證；按「清除本機存檔」才會換下一位（避免上一位的暱稱留在螢幕上）。

**host_led 模式**：你讀螢幕，請觀眾舉手決定下一條指令；到 seg7 的 block／pass 用**全場舉手投票**，記下票數。

## 3. 收集代碼與出統計

1. 把每位玩家的代碼貼進一個純文字檔，**一行一個**，例如 `codes.txt`。
2. 執行：
   ```
   python3 demo/tools/savelib.py aggregate codes.txt
   ```
   壞掉的行會被略過並提示原因（長度不符／校驗碼不符／雜湊鏈斷掉）。
3. 輸出包含：
   - 參與數、完成數、時間到的人數、完成率
   - 完成者的中位數時間
   - block／pass 票數
   - 需要完整提示的比例
   - 每一題的中位數耗時（找出卡關點）
   - **排行榜**（分數 → 較早完成）

範例見 `sample/crowd_report.txt`（40 位合成玩家）。

**單一玩家**：
```
python3 demo/tools/savelib.py verify  <代碼或檔案>     # 完整／可疑／損毀（可疑會列出原因）
python3 demo/tools/savelib.py card    <代碼或檔案>     # 重印值班證
python3 demo/tools/savelib.py import  <代碼或檔案>     # 預覽匯入正式版後的起始狀態
```

## 4. 現場排行榜與投票牆

- 排行榜：活動中每收十個代碼就跑一次 `aggregate`，投影或寫在白板上。
- 投票牆：block 與 pass 兩欄劃正字。這個結果可以做成社群貼文：「今晚 02:00 的訪客，大家選擇了 ___」。

## 5. 活動後

- [ ] 把 `aggregate` 的 JSON 存起來（作品集的數據來源）。
- [ ] 挑 3 張值班證截圖（取得玩家同意；只含暱稱，不含真名）。
- [ ] 記下現場觀察：哪一題大家最常卡住、哪個發現最先被找到、有沒有人看不懂的字。這些回頭改 `quests/*.yaml` 的提示。
- [ ] 若有收通知名單：發一封「正式版有進度」的短信，附 `save` 匯入說明。

## 6. 隱私

存檔只含：暱稱、隨機種子、事件、時間。不含真實姓名、不含 IP、不含裝置資訊。匯出前遊戲會顯示一次「這份代碼包含什麼」。收 email 必須是**另一個明示欄位**，與存檔代碼分開，且可不填。

## 7. 離線備案

- 網路掛了：試玩版是靜態網頁，載入完成後不需要網路；先在每台機器開好。
- 瀏覽器清掉存檔：看結尾代碼（強制顯示）。
- 代碼貼壞：請玩家重新複製；仍失敗就拍螢幕照片，事後你再手動輸入（代碼有校驗碼，打錯會被偵測到）。
