依 [DECISIONS](../DECISIONS.md) D06/D07/D12/D15/D17/D19/D20，自 M1 納入基礎，M5 驗收離線主線。共用 brief／證據／問題台帳見 [PLAYER_EXPERIENCE](PLAYER_EXPERIENCE.md)，畫面 S01–S10 見 [UI_HANDOFF](UI_HANDOFF.md)，狀態 ST01–ST29 見 [INTERACTION_SPEC](INTERACTION_SPEC.md)。

**結論：本輪只有來源檢視與設計規格，未執行符合性稽核，不宣稱通過 WCAG。** E10/E11 的 Chrome 自動驗收是歷史證據；真實手機軟鍵盤、NVDA／VoiceOver、forced-colors、400% 放大等仍待測。沒有真人樣本，問題頻率一律未知。

## 1. 範圍、標準與判定邊界

- 範圍：桌機主線十個 surface、兩模式、兩主題、三字級、所有關鍵狀態；手機先驗 Ch0 與保存／匯入。M6 認證／同步及 M7 賽季在相應版本另驗。
- 規範：[WCAG 2.2](https://www.w3.org/TR/WCAG22/) 與 [Understanding](https://www.w3.org/WAI/WCAG22/Understanding/)。準則與例外以正式文字為準；下表是工作分組，不能替代全部適用 A/AA 準則盤點。
- **2.5.8 AA：24×24 CSS px**，或符合間距／其他正式例外。**44×44 CSS px 是本專案推薦，對應 2.5.5 AAA 的尺度與例外**；不是 AA 最小值，也不是 44pt／48dp 的同義詞。
- 文字對比 1.4.3 AA：一般文字≥4.5:1，大字≥3:1。大字為18pt（24 CSS px）一般或14pt（約18.67 CSS px）粗體／等效 CJK；19px 普通字不自動是大字。
- 非文字 1.4.11 AA 的必要邊界／圖形與相鄰色≥3:1，需依適用範圍／例外判定。focus 2.4.7 可見、2.4.11 不完全被作者內容遮住；本案額外希望整個焦點可見。2.4.12／2.4.13 是 AAA，不拿通用2px框當整體合格證明。
- 優先序由阻斷程度決定，不用 AAA／AA 等級推斷嚴重度。自動掃描分數不等於符合性；截圖不能驗證鍵盤／語音／取消／時間。

## 4. 長 log 與增量讀屏詳細契約（A11Y-005）

現況 Terminal 的1200上限是**輸出 DOM 區塊數**，單個區塊可很長；不能當百萬行日誌的可讀／記憶體保證。

1. **提交才發布：** durable 須 IDB 原子提交成功，已明選 volatile 須 memory adapter 提交成功，才發布新世界／結果；輸出以 `inputId` 關聯並由呈現層穩定去重，不新增引擎 wire ID。quota 時只播「本次尚未提交、原進度保留」及恢復出口，不播候選的任務完成。volatile 持續可讀「未保存至本機」，下載成功不改成已持久保存；現行 demo best-effort 另列測例。
2. **常規短輸出：** 每次命令完成一次摘要（命令結束／任務變更／保存例外），polite。輸入回顯不再作完整live播報，避免聽見自己輸入兩次。
3. **大量輸出：** 超過工程設定的可讀範圍時，先播「已產生輸出，可讀摘要或逐段查看」與實際範圍；有真實總數才報總數。全文採非live、可選取／分段到達的歷史區；**摘要 live 與全文 live 不同時啟用**。
4. **不截斷理解：** 分頁按鈕有「較早／較新、第x範圍」及可回到原位置；提供已解鎖檔案的再次查閱／搜尋，不許 DOM 淘汰使唯一證據永遠不可取。不能以無限滾動作唯一方法。
5. **尊重閱讀游標：** 正在閱讀的區塊不可因收到新結果而刪除／重掛；到容量邊界停止自動新增呈現，顯示待讀摘要。離開該範圍後才可回收，保留取回方式。工程需定義上限與快取，未定前不承諾「保留全部輸出」。
6. **宣讀控制：** 提供「僅摘要／宣讀新結果／暫停自動宣讀」偏好（提案）；暫停時畫面保留待讀數及讀取入口。錯誤摘要仍可按需讀；緊急資料損失警告最多一次 assertive，其餘 polite。
7. **增量更新：** 不每250ms播時間／保存狀態；只在有意義轉移（保存失敗、恢復成功）更新live。clock顯示可視更新但非每秒live；活動提醒亦不逐秒轟炸。
8. **驗收例：** 讀舊段落時新增100段輸出、觸發裁切邊界、執行取消、重新進入分頁、模式切換；NVDA／VoiceOver應能續讀原段、只收到一次正確摘要、找回新內容，無自動跳底。100段是測試fixture，不是產品上限。

## 6. 字幕、認知與不可見字元

**A11Y-010：無音效必需。** 目前主體純文字；未來任何門鈴、訪客、Boss提示、到時提醒，都需同時有可見且可被AT讀到的文字，不要求聽音高／左右聲道／節奏才能解題。字幕附說話者及必要非語音如「[機房風扇停止]」，不能只是裝飾性「…」。若加入影片，依是否預錄／即時、有聲／無聲評 captions、transcript、audio description，不一律以「已有文字」免驗。

**A11Y-009：** command、路徑與符號提供可查操作解釋；畫面軟換行不改命令。允許貼上、不把打字速度視為知識證據。八空格／不可見字元可先準備「顯示空白標記／位置／字元種類」的等價檢視能力，但何時揭露、顯示到什麼程度、能否計數，要作者與謎題設計確認。不可在 `aria-label` 暗送完整答案，也不可只讓視覺玩家看見必要空格線索。這是 **UX-O03 blocking**，不是可砍的無障礙附加項。

manual三階提示、免費man、skip後可回顧降低記憶負荷；提示不能因讀得慢自動洩答。完整解法不是「無障礙模式」專屬；任何人可用。流程與詳解不以障礙身分給不同劇情結局或較低價值標籤。

- 角色成本（未校準）：A11Y-001/002/003/006/007 基礎 FE＋QA 為 M；005 長log工程＋AT為 L；008時間與009謎題和引擎／作者共用成本，不重複加總；真機與AT驗收 M–L，設備取得與測試者報酬另列。S/M/L定義見 brief。
- blocking：已確認的任務阻斷、資料損失、關鍵鍵盤／讀屏失效須修復複驗；尚無關鍵平台證據不能發布該平台支援聲明。其他適用 A/AA 不符合未處理時不能聲稱符合 WCAG；不得只靠「零Critical」作認證。
- nonblocking：44px以上擴大、AAA更強焦點、裝飾動畫等超出AA且不造成實際阻斷的細節；但未達24px又無有效例外不可降為裝飾問題。
- 退出：需求逐列有可追溯證據，未測與例外有理由／責任；與 [PLAYTEST_PLAN](PLAYTEST_PLAN.md) 的障礙使用者觀察合併根因。真人順利完成不能代替準則測試，準則測試也不能代替理解研究。
