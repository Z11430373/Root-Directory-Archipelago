## 候選選定

- **候選**：Pyodide 314.0.8（npm 套件）
- **下載量**：tarball 6,487,361 bytes（6.2 MiB 壓縮），解壓後 13,876,577 bytes（13.2 MiB），14 個檔
- **來源**：`npm view pyodide dist.tarball` → `https://registry.npmjs.org/pyodide/-/pyodide-314.0.8.tgz`
- **量測命令**：`curl -sL <url> -o pyodide.tgz && tar -xzf pyodide.tgz && python -c "import os; ..."`（見上方）
- **環境**：Windows 11, Python 3.12（僅量測下載量，未在瀏覽器執行）
